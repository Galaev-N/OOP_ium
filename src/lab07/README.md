# Лабораторная работа 7 — Консольное приложение

## 1. Цель работы

В лабораторной работе реализовано консольное приложение для предметной области интернет-магазина. Использованы классы из предыдущих лабораторных, типизированная коллекция из ЛР-6, сортировка и фильтрация, собственные исключения и сохранение данных в JSON.

## 2. Структура проекта

- `main.py` — точка входа, запуск приложения.
- `cli.py` — консольное меню, ввод и вывод данных.
- `app.py` — бизнес-логика: добавление, удаление, поиск, сортировка, фильтрация.
- `storage.py` — сохранение и загрузка данных из JSON.
- `exceptions.py` — собственные исключения.

Приложение использует модели из `lab05` и контейнер `TypedCollection` из `lab06` или `lab006`.

## 3. Описание CLI

В меню реализованы операции:

1. Добавить товар.
2. Показать все товары.
3. Найти товар по ID.
4. Удалить товар с подтверждением.
5. Сортировать товары.
6. Фильтровать товары.
7. Показать доступные товары.
8. Применить трансформацию.
9. Показать статистику.
0. Сохранить данные и выйти.

Ошибки ввода обрабатываются через исключения. При добавлении объекта с повторяющимся ID вызывается `DuplicateItemError`. При удалении несуществующего объекта вызывается `ItemNotFoundError`.

## 4. Демонстрация работы

Для отчета нужно добавить скриншоты:

- запуск приложения и автозагрузка данных;
- добавление товара;
- вывод таблицы товаров;
- сортировка по цене или названию;
- фильтрация по категории или цене;
- удаление с подтверждением;
- выход и повторный запуск с сохраненными данными.

## 5. Вывод

В работе было реализовано приложение с разделением на слои. Были применены CLI-интерфейс, собственные исключения, типизация, работа с JSON-файлом, сортировка и фильтрация коллекции.
